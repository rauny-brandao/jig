# Security

jig downloads and installs executables, so security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub private vulnerability reporting](https://github.com/rauny-brandao/jig/security/advisories/new)
with:

- what is affected (package, function, manifest field),
- how to reproduce it,
- the impact you expect (for example: path traversal during extraction, checksum bypass).

You'll get a reply within 7 days.

## Supported versions

Before v1.0, only the latest release gets fixes.
